# Python User Configuration Manager

A beginner-friendly Python project developed as part of the freeCodeCamp Python curriculum. This project demonstrates how to manage user settings using Python dictionaries, tuples, functions, conditionals, loops, and string methods.

## Features

- **Add settings:** Add new configuration options with lowercase keys and values.
- **Update settings:** Modify existing settings while handling missing keys.
- **Delete settings:** Remove configuration options from the dictionary.
- **View settings:** Display all saved settings in a readable format.
- **Input normalization:** Convert keys and values to lowercase for consistency.
- **Error handling through return messages:** Provide clear feedback when a setting already exists or cannot be found.

## Example

The project uses a dictionary to store user preferences, such as theme, notifications, and volume.

```python
test_settings = {
    'theme': 'dark',
    'notifications': 'enabled',
    'volume': 'high'
}
```

These settings can be added, updated, deleted, and displayed using the implemented functions.
